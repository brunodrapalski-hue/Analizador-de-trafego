# Analisador de Tráfego

Projeto desenvolvido para captura, processamento e análise de tráfego de rede.

## Estrutura do projeto

- `app/` — código principal da aplicação
- `tests/` — testes automatizados
- `docs/` — documentação do projeto
- `data/` — dados gerados durante as análises
- `samples/` — arquivos de exemplo para testes

## Tecnologias

- Python
- Docker
- Git
- WSL 2
- Ubuntu 24.04
